# Examples

Examples are organized by purpose:

- `plans/api/` — API test plans.
- `plans/data-driven/` — data-driven plans.
- `suites/` — suite definitions.
- `data/json/` — JSON datasets.
- `requirements/` — natural-language requirements.
- `legacy/` — compatibility examples from earlier releases.

Examples are safe templates; do not add production credentials or private data.
